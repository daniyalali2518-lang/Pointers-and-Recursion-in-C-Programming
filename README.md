# Pointer Operations and Recursive Problem-Solving

This assignment focuses on implementing pointers and recursion in C programming to perform memory-based operations and mathematical calculations. It demonstrates how functions can manipulate variable values and solve problems through repeated recursive calls. Each task strengthens logical thinking, programming fundamentals, and the ability to develop efficient solutions.

1. Pointer Swapping:
   Exchanges the values of two variables using pointers and a temporary variable.

3. Double Pointer Manipulation:
   Modifies the value of a variable using a double pointer.

5. Circular Shifting:
   Rearranges three variable values in a circular order using pointer-based operations.

7. Recursive Fibonacci:
   Generates the first 25 Fibonacci numbers using a recursive function.

9. Recursive Summation:
    Calculates the sum of the first 25 natural numbers through recursion.

11. Recursive GCD:
    Determines the Greatest Common Divisor (GCD) of two integers using a recursive Euclidean algorithm.
